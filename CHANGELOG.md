# Changelog

All notable Mirage changes are documented here.

## [v0.1.0] - 2026-08-12

### Added

- Initial public release of Mirage for single-host temporary links and preview environments.
- CLI, private API, and dashboard for token-scoped spaces and links.
- Assigned-port host processes with loopback health-gated Caddy routing.
- TTL expiry, restart controls, logs, and startup reconciliation.
- Optional installation-wide administration tokens.
- systemd deployment, wildcard DNS, and Zero Trust connector guidance.

Mirage deployment in Docker or Kubernetes is not supported in v0.1.0. Docker may be used for a third-party Zero Trust connector.
